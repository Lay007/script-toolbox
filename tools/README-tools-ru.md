# Инструменты контроля качества репозитория

В этой папке находятся лёгкие проверки репозитория, которые используются в CI и при локальном ревью.

Скрипты специально сделаны безопасными: они анализируют файлы и документацию, но не выполняют setup-скрипты, изменяющие конфигурацию Windows.

## Скрипты

| Скрипт | Назначение | Выполняет setup-скрипты? |
|---|---|---|
| `test-powershell-syntax.ps1` | Разбирает все `.ps1` файлы репозитория через PowerShell AST parser | Нет |
| `test-markdown-links.ps1` | Проверяет относительные ссылки в Markdown-документации | Нет |

## Локальный запуск

Проверка синтаксиса PowerShell:

```powershell
pwsh -NoProfile -File tools/test-powershell-syntax.ps1
```

Проверка относительных ссылок Markdown:

```powershell
pwsh -NoProfile -File tools/test-markdown-links.ps1
```

## Роль в CI

Эти инструменты запускаются в workflow PowerShell lint перед более глубоким статическим анализом. Они быстро выявляют синтаксические ошибки и устаревшие локальные ссылки в документации.

См. также [CI quality gates](../docs/ci-quality-gates.md).
